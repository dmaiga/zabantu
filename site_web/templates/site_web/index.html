Economy | Conflict | State

Vers une recherche ancrée dans les dynamiques économiques et sociales

Zabantu, inspiré d'une plante mandingue, est un groupe de recherche pluridisciplinaire travaillant sur le nexus Économie-Conflit-État. Nos travaux portent sur les dynamiques économiques, les conflits armés et les politiques publiques, dans le paradigme d'une recherche ancrée sur les réalités locales.
