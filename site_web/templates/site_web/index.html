Vers une recherche ancrée dans les dynamiques économiques et sociales

Zabantu, inspiré d'une plante mandingue, est un groupe de recherche pluridisciplinaire travaillant sur le nexus Economie-Conflit-Etat. Nos travaux sont principalement axés sur la compréhension des dynamiques économiques, de conflit armé, des politiques publiques; dans le paradigme d'une recherche ancrée sur les réalités locales.
